VELVET FOX — A Midnight Heist: a top-down stealth heist game. Slip past patrolling guards and their vision cones, dodge security cameras, grab the loot and the Star, and escape before the alarm fills or the timer runs out. Three playable heists, smoke bombs, coin distractions, and a live alarm meter.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in your browser.
